# Portfolio Website 🌐✨

This project is an interactive personal portfolio website built as part of the Code Blossom Full-Stack Development curriculum. The aim is to improve a previously static portfolio by adding JavaScript-driven interactivity, improving usability, and following clean frontend development practices.

The project is structured so that other developers can easily understand, extend, or improve it.

### 🔗 Live Demo & Walkthrough

[Live Site](https://maggycodes.netlify.app/)

[Video Walkthrough](https://www.loom.com/share/2c1cb5370d9743a3bbc081c131a51761)

### 🛠 Tech Stack

- HTML – Semantic structure and content

- CSS – Styling, layout, and responsive design

- JavaScript (Vanilla JS) – Interactivity and dynamic behavior

- Deployment: Netlify

⚠️ No frameworks are used in this project.

### ✨ Features

- Responsive layout for desktop and mobile devices

- Mobile-friendly navigation menu

- Interactive tabs in the About section

- Contact form with client-side validation

- Smooth scrolling and UI interactions

### 🧠 JavaScript Concepts Used

This project demonstrates several core JavaScript concepts:

Event Listeners – Handling user interactions (clicks, form actions)

Form Validation – Validating user input before submission

These features improve usability and make the site more engaging.
